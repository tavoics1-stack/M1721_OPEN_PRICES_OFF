# Licencias y atribución

Los precios proceden de Open Prices, proyecto de Open Food Facts, y los atributos de producto de Open Food Facts y sus contribuyentes. La revisión OP utilizada está identificada en el manifiesto de fuentes.

Las copias oficiales archivadas de la ficha del dataset, la guía de datos y los términos OFF documentan Open Database License (ODbL 1.0) para las bases y Database Contents License (DbCL 1.0) para contenidos OFF. Las proyecciones y el dataset integrado siguen siendo derivados de esas fuentes: reducir columnas no elimina sus obligaciones de atribución y compartir-igual cuando sean aplicables.

No se redistribuyen imágenes. Las licencias de las fotografías de producto y de proofs no se trasladan al código propio ni se confunden entre sí. La licencia del software servidor de Open Prices tampoco es la licencia de sus datos.

El código nuevo es trabajo académico del Grupo 2. No se ha asignado una licencia de software sin decisión del titular. Se entrega para revisión académica; elegir y añadir una licencia explícita de código es una decisión humana previa a presentar el repositorio como software de libre reutilización.

Referencias: https://world.openfoodfacts.org/terms-of-use y https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/tutorials/license-be-on-the-legal-side/ .
